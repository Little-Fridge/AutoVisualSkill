# Task Execution Case Sources

These files support the README previews. Static task comparisons use the same
downstream task under two model inputs:

- without generated skill: task image(s) plus the task prompt only;
- with generated visual skill: task image(s), the generated `skill.md`, and
  any visual prior, runtime-state reference, or interleaved reference images
  used by that skill.

The model used for the recorded runs is `gemini-3-pro-preview` through an
OpenAI-compatible endpoint. API credentials were supplied through environment
variables at runtime and are not stored in this repository.

Files:

- `task_execution_results.json`: raw and parsed model responses for each
  without-skill and with-skill run. README text summarizes these responses
  outside the preview images.
- `assets/gui_hard_hitbox_task.png`: harder GUI hitbox task where the search
  glyph is intentionally off-center inside a larger clickable hitbox.
- `assets/table_heldout_task.png`: held-out table image for testing the
  row/column intersection skill on a different table from the generated prior.
- `assets/chart_heldout_task.png`: held-out bar chart image for testing
  projection on a different chart from the generated prior. This chart includes
  a misleading floating label (`80`) above bar C; the comparison checks whether
  the model trusts that label or projects the bar top to the y-axis.
- `assets/counting_hard_task.png`: harder red-token counting task where only
  red circles with white center dots count; solid red, blue, purple, and gray
  shapes are distractors.
- `assets/counting_hard_task_runtime_overlay.png`: current-task runtime anchor
  overlay and counter badge generated by executing the dense-counting dynamic
  visual skill.
- `assets/line_heldout_task.png`: held-out line graph for testing line tracing
  without reusing the showcase runtime trace.
- `assets/geometry_heldout_task.png`: held-out isosceles-triangle task for
  testing auxiliary-line construction on a different diagram.
- `assets/odd_one_out_hard_task.png`: harder shape-anomaly search task with
  many tiny repeated icons and color-accent distractors.
- `assets/odd_one_out_hard_task_runtime_overlay.png`: current-task runtime
  search overlay generated by executing the odd-one-out dynamic visual skill.
- `assets/ppt_heldout_task.png`: held-out slide draft for testing the
  presentation critique skill without using the original critique overlay as
  the task image.
- `assets/pythagorean_heldout_*.png`: held-out frame sequence for testing
  interleaved visual proof binding.
- `assets/remote_ssh_heldout_*.png`: held-out documentation screenshots for
  testing interleaved procedure binding.
- `assets/visual_colleague_heldout_slide.png`: held-out slide draft used to
  test whether the visual colleague skill binds new critique/redraw decisions
  to chat-grounded visual references.
- `assets/counting_task.png`: cropped source image for the dense-counting
  legacy downstream task.
- `assets/line_tracing_task.png`: cropped source image for the line-tracing
  downstream task.
- `assets/odd_one_out_task.png`: cropped source image for the odd-one-out
  legacy downstream task.

Run `python tools/render_task_outcome_comparisons.py` to regenerate the README
preview images from the recorded task-execution results and curated references.
The static comparison previews are visual-only: they show model-selected
locations or projection evidence, while the model answers are rendered as normal
README text. Dynamic previews show runtime visual state traces and, where
recorded, the without/with task-result difference. Interleaved previews show
ordered evidence references without a without/with comparison. The task images
are held-out from the images used to generate each curated visual skill, so
source priors are references rather than answer keys for the current task.
Dynamic runtime overlays, such as counting anchors and checked odd-one-out
candidates, are generated on the current task image as the skill's visible
working state.
