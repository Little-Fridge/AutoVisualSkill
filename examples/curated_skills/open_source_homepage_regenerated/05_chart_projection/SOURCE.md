# Source

This showcase uses a synthetic, repo-owned bar-chart screenshot as input:
`assets/source_bar_chart_c_value.png`.

The visual prior was generated by running AutoVisualSkill with
`gemini-3-pro-preview`. Gemini selected the `overlay` visual-prior strategy and
returned a sparse overlay plan; AutoVisualSkill rendered that plan onto the
source screenshot with its fixed local overlay renderer.

Generation prompt:

```text
Create a static visual skill for reading the value of bar C in a simple bar chart. Use the provided bar chart image as concrete visual material. Prefer the overlay visual-prior strategy: preserve the source image and add sparse non-prose marks for the selected bar and a straight projection guide to the y-axis. Do not create an abstract standalone diagram.
```
