# Source Attribution

This curated showcase uses synthetic, repo-owned multimodal chat data. It does
not contain real personal data.

- `source_multimodal_chat.md`: synthetic chat export used as source input.
- `source/mira_chat_thread_review.png`: synthetic chat screenshot with a draft
  slide and the colleague's region-marked critique attachment.
- `source/mira_chat_thread_revision.png`: synthetic follow-up chat screenshot
  with a rejected/approved slide comparison and visual style snippets.
- `source/input_contact_sheet.png`: compact preview of the mock source inputs.
- `assets/annotated_anti_patterns.png`: source-backed visual reference
  extracted by the generated skill for the colleague's critique-marking style.
- `assets/hierarchy_comparison.png`: source-backed before/after reference for
  the colleague's preferred redraw direction.
- `assets/visual_snippets.png`: source-backed palette, typography, and diagram
  habit reference.

The skill was generated by a recorded AutoVisualSkill run using
`gemini-3-pro-preview` through an OpenAI-compatible endpoint. API credentials
were supplied through environment variables and are not stored in the
repository.
