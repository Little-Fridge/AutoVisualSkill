# Source

This showcase uses a synthetic, repo-owned toolbar screenshot as input:
`assets/source_toolbar_search_button.png`.

The visual prior was generated by running AutoVisualSkill with
`gemini-3-pro-preview`. Gemini selected the `overlay` visual-prior strategy and
returned a sparse overlay plan; AutoVisualSkill rendered that plan onto the
source screenshot with its fixed local overlay renderer.

Generation prompt:

```text
Create a static visual skill for clicking the search button in a simple toolbar screenshot. Use the provided toolbar image as concrete visual material. Prefer the overlay visual-prior strategy: preserve the source image and add sparse non-prose marks for the clickable button envelope and click center. Do not create an abstract standalone diagram.
```
