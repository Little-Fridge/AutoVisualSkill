# Source Attribution

This curated showcase combines synthetic, repo-owned preview assets with one
public-source application trace.

- `assets/text_only_slide_draft.png`: intentionally generic first-pass slide.
- `assets/design_critique_overlay.png`: synthetic runtime critique overlay.
- `assets/visual_skill_assisted_slide.png`: cleaner redraw that preserves the
  same slide content.
- `assets/slide_redraw_runtime_trace.png`: three-step real PPT application
  trace: input slide, red runtime critique overlay with region-linked redraw
  actions, and skill-assisted redraw.
- `assets/heldout_text_only_redraw.png`: rendered repair from the text-only
  Gemini redesign plan on the held-out slide task.
- `assets/heldout_visual_skill_redraw.png`: rendered repair from the Gemini
  visual-skill run after applying spatial critique regions to the held-out
  slide task.
- `assets/style_reference_board.png`: reusable visual constraints for the
  professional slide style demonstrated by this showcase.

The assets contain placeholder content only and are not copied from a real
presentation or brand system.

The real PPT application trace uses a public NASA HEAT teaching slide from
NASA's "HBY and Math 3: The Sun Touches Everything" resource page:

https://science.nasa.gov/learn/heat/resource/hby-math-3-the-sun-touches-everything/

- `assets/real_ppt_nasa_albedo_input.png`: rendered "January 2024: Albedo"
  slide used as the real input.
- `assets/real_ppt_nasa_critique_overlay.png`: runtime critique overlay
  generated by applying the AutoVisualSkill slide critique protocol.
- `assets/real_ppt_nasa_skill_redraw.png`: polished skill-assisted redraw that
  preserves the original scientific content.
- `assets/real_ppt_nasa_skill_trace.png`: three-step trace used in the README
  and Gradio preview, with region-linked redraw actions shown next to the
  runtime critique overlay.
- `real_ppt_agent_output.json`: structured critique regions and redraw spec
  produced by the agent run.

NASA names and marks appear only as part of the source slide attribution. This
project is not affiliated with or endorsed by NASA.
