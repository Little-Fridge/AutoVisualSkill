# Source

This showcase uses a synthetic, repo-owned 4x4 table screenshot as input:
`assets/source_table_row_c_col_q3.png`.

The visual prior was generated by running AutoVisualSkill with
`gemini-3-pro-preview`. Gemini selected the `overlay` visual-prior strategy and
returned a sparse overlay plan; AutoVisualSkill rendered that plan onto the
source screenshot with its fixed local overlay renderer.

Generation prompt:

```text
Create a static visual skill for finding the cell at row C and column Q3 in a simple 4x4 table. Use the provided table image as concrete visual material. Prefer the overlay visual-prior strategy: preserve the source image and add sparse non-prose marks for the target row band, target column band, and intersection cell center. Do not create an abstract standalone diagram.
```
